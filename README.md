# 깃 과 깃허브
- - - -
## 깃
#### **Git**은 로컬설치를 통해 오프라인으로 ***수정이력***, ___버전___ 을 관리하는 소프트웨어이다.
- __깃으로 버전 관리하기__
  - 깃 저장소 만들기
  - 버전 만들기
  - ~~커밋 내용 확인하기~~
  - 작업 되돌리기
- __깃과 브랜치__
  - 브랜치 만들기 및 이동하기
  - 브랜치 커밋하기
  - 브랜치 병합하기

## 깃허브
#### [GitHub](https://github.com/)는 설치 필요 없이 온라인으로 ***공유***, ***협업*** 이 목적인 호스팅 서버이다.
- __깃허브 시작하기__
  - 깃허브 가입하기
  - 지역 저장소를 원격 저장소에 연결하기
  - 깃허브에 SSH 원격 접속하기
- __깃허브로 협업하기__
  - 서로 다른 컴퓨터에서 원격 저장소 함께 사용하기
  - 원격 브랜치 정보 가져오기
  - 원격 저장소에서 협업하기 깃 과 깃허브
